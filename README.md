# 🎓 Student Management System

A beginner-friendly Student Management System built in Python using file handling.

This project allows users to manage student records through a menu-driven interface. Student data is stored in a text file (`student.txt`) without using a database.

---

## 📌 Features

- ✅ Add Student
- ✅ View All Students
- ✅ Search Student by ID
- ✅ Update Student Information
- ✅ Delete Student
- ✅ Calculate Average Age
- ✅ Display Toppers (Grade A*)
- ✅ Count Total Students
- ✅ Create Backup of Student Records
- ✅ Prevent Duplicate Student IDs
- ✅ Handle Missing Files and Empty Files
- ✅ Input Validation

## 📄 Student Record Format

Each student is stored in the following format:

```
ID,Name,Age,Grade
```

Example:

```
101,John,18,A*
102,Sarah,19,A
103,Ali,20,B+
```
